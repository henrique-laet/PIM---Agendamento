# VitaCare — Sua saúde, organizada.

Sistema web de agendamento de consultas médicas, desenvolvido como PIM da UNIP
(Análise e Desenvolvimento de Sistemas).

## Portais
- **Paciente:** cadastro, login, agendamento, acompanhamento e cancelamento de consultas
- **Administrador:** gestão de médicos, pacientes e agendamentos

## Tecnologias
C# · ASP.NET Core · Dapper · PostgreSQL · HTML/CSS/JS · VLibras

## Estrutura
- `backend/` — API em ASP.NET Core
- `frontend/` — interfaces do paciente e do administrador
- `docs/` — documentação do projeto
- `_legado/` — versão anterior (apenas para consulta)
